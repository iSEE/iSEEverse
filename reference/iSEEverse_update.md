# Update iSEE and the whole iSEEverse

Update iSEE and the whole iSEEverse

## Usage

``` r
iSEEverse_update(repos = getOption("repos"))
```

## Arguments

- repos:

  The repositories to use to check for updates. Defaults to
  getOption("repos").

## Value

An invisible NULL or the suggested commands to update the corresponding
packages.

## Examples

``` r
if (FALSE) { # \dontrun{
iSEEverse_update()
} # }
```
